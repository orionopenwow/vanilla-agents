# Change guide: what the owner asks for, and exactly where it lives

Every visual and every sentence is a setting under `app/config/`. To change something: edit the one key below, run `python -m vanilla_agents.app.check` (plain-language errors), run the tests, look at the window, commit.
A test fails if any setting is missing from this file, or if this file names a setting that does not exist. `*` stands for any name at that spot.
